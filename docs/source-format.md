# Source format of a pack

Everything a pack ships, except its `descriptor.mod` and `thumbnail.png`, is generated by `build.ps1 -Generate` from `source/<pack>/`. This page describes those files. `build.ps1 -Check` enforces every rule here.

## `events.json`

```json
{
    "pack": "finland",
    "tag": "FIN",
    "namespace": "ep_fin",
    "displayName": "Finland",
    "events": [
        {
            "id": 1,
            "key": "isthmus_volunteers",
            "title": "Volunteers on the Isthmus",
            "desc": "First paragraph.\n\nSecond paragraph.",
            "picture": "abatis",
            "factSheet": "isthmus_volunteers",
            "anchors": ["Karelian Isthmus", "Taipale", "Summa"],
            "fire": { "after": "1937.5.1", "before": "1937.9.1", "chance": 10, "trigger": "has_war = no" },
            "options": [
                { "name": "Every metre counts.", "ai": 70, "effects": [ { "war_support": 0.02 }, { "timed_idea": "volunteer_work", "days": 120 } ] },
                { "name": "Send them home before the harvest.", "ai": 30, "effects": [ { "political_power": 25 } ] }
            ]
        }
    ],
    "ideas": [
        { "key": "volunteer_work", "name": "Volunteer Work on the Isthmus", "desc": "...", "picture": "generic_morale_bonus", "modifier": { "war_support_factor": 0.03 } }
    ]
}
```

| Field | Rule |
|---|---|
| `namespace` | `ep_` and the tag in lower case. Never changes after a release: saves hold the guard flags `ep_<tag>_fired_<id>`. |
| `id` | Whole number from 1, unique in the pack, never reused or renumbered after a release. The event is `<namespace>.<id>`. |
| `key` | Lower-case letters, digits, underscores; names the fact-sheet section by default. |
| `title`, `desc`, option `name` | English, plain ASCII punctuation, no double quotes (use single quotes), and none of the characters the localisation reads as markup: square brackets [LOC-004] [LOC-006], the section and pound signs [LOC-009], the hash sign, and the dollar sign (a lone one is harmless [LOC-015]; it is refused to keep the texts plain). `desc` 40 to 170 words, at most 2,226 characters [GUW-046]; `\n\n` between paragraphs. The text rules are in `docs/style-guide.md`. |
| `anchors` | At least two names, places, dates or figures from the fact sheet; at least two must appear in `desc` word for word. |
| `picture` | A key of `pictures.json`, or `vanilla:GFX_report_event_<name>` for a picture of the base game [SPR-028]. |
| `fire.after`, `fire.before` | `YYYY.M.D`; the event can fire only between them [SCR-091]. |
| `fire.chance` | Percent per week, 1 to 100 [SCR-089]. 5 to 15 spreads an event over a few months; 100 fires it in the first week. |
| `fire.trigger` | Optional Clausewitz trigger lines, checked in the country's scope every week. Only the pack's own flags and vanilla triggers: never another pack's names. |
| `ai` | The option's `ai_chance` factor: an AI-controlled country also gets the pack's events and picks an option by these weights [SCR-093]. |
| `effects` | A list of one-key objects: `stability`, `war_support` (shares of one, at most 0.03 either way [SCR-088]), `political_power` (at most 50 either way), `timed_idea` with `days` (at most 180) [SCR-090]. |
| `ideas` | Timed ideas only; `picture` from `data/effect-caps.json`; one to three modifiers from the list and caps there. Name and description follow the text rules. |

## `pictures.json`

Written only by `build.ps1 -FetchPicture`, which reads the licence from the Wikimedia Commons API and refuses anything but public domain (with a `PD-` template stating why), CC0 or CC BY (with a named author), a file tagged for deletion or dispute, a file that is not a picture, and a download outside Wikimedia's servers. `build.ps1 -Check` derives the licence category from the recorded Commons code again, requires the Commons page and download URLs, the hash and the fetch date, and compares the hash with the cached download; `-Audit` warns about a licence read more than 180 days ago. Fetching a picture again keeps its crop and tone unless new ones are given. Each row keeps the Commons title and page, the download URL and its SHA-256, author, credit, licence, licence URL, Commons restrictions, the original date and size, the crop (`0` to `100`, `50` centres; or `fit`), the tone (`none`, `grey`, `warm`) and the date it was fetched. To change a crop or tone, fetch the picture again with the new values.

## `fact-sheets.md`

One section per event, headed `## <key>`, with the facts the text may use, each with its source URL. The event's text may use nothing else; the editor cuts what is not here.

## `workshop-intro.bbcode`

The opening of the pack's Workshop description in Steam BBCode. `-Generate` adds the event list and the picture credits after it.

## Generated files

| File | From |
|---|---|
| `packs/<pack>/events/ep_<tag>_events.txt` | the events; every one `is_triggered_only` |
| `packs/<pack>/common/on_actions/ep_<tag>_on_actions.txt` | one `on_weekly_<TAG>` anchor per event: guard flag, dates, trigger, weekly chance [SCR-080] [LOAD-011] |
| `packs/<pack>/common/ideas/ep_<tag>_ideas.txt` | the ideas |
| `packs/<pack>/interface/ep_<tag>_event_pictures.gfx` | one sprite per picture used |
| `packs/<pack>/gfx/event_pictures/ep_<tag>/*.dds` | `build.ps1 -ConvertPictures`: 210x176 uncompressed DDS |
| `packs/<pack>/localisation/<language>/ep_<tag>_l_<language>.yml` | the English text in all ten languages [LOC-017], UTF-8 with BOM [LOC-001] |
| `packs/<pack>/WORKSHOP_DESCRIPTION_GUIDELINES.md` | intro, event list, picture credits |
| `wiki/Event-Pack-<Country>.md` | event table with pictures and licences |

Nothing else may sit in `packs/<pack>/`: `-Check` fails on any file there that is not `descriptor.mod`, `thumbnail.png`, a generated file or the picture of a used manifest row, so nothing ships unchecked. `build.ps1 -PreviewPictures -Pack <pack>` writes PNG copies of the pictures to `scratch/preview/<pack>/` for a look at the crops.
